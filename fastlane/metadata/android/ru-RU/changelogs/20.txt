• Discord и YouTube убраны из всех проверок: цели пинга, адреса проверки DPI-стратегий, проверка канала. Появилась масса конфигов, которые открывают только эти два сервиса — по ним нельзя судить, работает ли обход на самом деле. Теперь проверки идут на GitHub, Instagram, X, Facebook, LinkedIn.
• Исправлено: рабочие конфиги больше не помечаются неактивными. Ответ «204 без тела» (обычное дело для «белых» каналов, которые пускают только Cloudflare и Google) теперь считается доказательством работы, а не провалом — раньше такой конфиг уходил в чёрный список и удалялся из пула. В короткой проверке для этого всегда пробуется один такой адрес.
• Новый экран «Рабочие конфиги»: весь пул списком, у каждого — пинг, перемер скорости, удаление из рабочих и отправка в чёрный список. Внизу — «В чёрный список все нерабочие» после общей проверки. Открывается из настроек и нажатием на карточку пула.
