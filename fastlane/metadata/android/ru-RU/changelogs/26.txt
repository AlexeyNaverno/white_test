• Раздельное туннелирование: российские сайты и приложения больше не идут через VPN. Сайты — по встроенному списку доменов (.ru/.рф целиком плюс Яндекс, VK, банки, госуслуги, маркетплейсы, операторы, карты, такси), приложения — исключением из tun (addDisallowedApplication). Оба механизма включаются в «Обход → Российское — мимо VPN», свои домены и пакеты добавляются полями.
• Быстрая проверка в три ступени: быстрый TCP-отсев по серверам (900 мс, 384 потока, конфиги группируются по host:port — 1200 строк проверяются за секунды), затем полный пинг с TLS, затем замер скорости. Отсеянные в чёрный список не попадают.
• Меньше объёмов по умолчанию: 8 источников вместо 12 (полный набор возвращается кнопкой) и лимит хранилища 1200 конфигов вместо 2000 — настраивается.
• «Связность есть, скорость не измерена» теперь уходит в чёрный список на всех путях: при подключении одной кнопкой, при импорте списка и при вставке из буфера.
• Для видимости установленных приложений добавлено разрешение QUERY_ALL_PACKAGES — без него исключение приложений из VPN на Android 11+ не работало бы.
