# 0.1.1 — vmess снова проверяются, замер через реальный список, поиск без POST

## Что нового

- **Массовый ложный отказ «vmess: нет id» устранён.** Ошибка была в разборе base64: у ссылок,
  чья длина без «=» не кратна четырём на три, добавлялось три символа «=» вместо одного,
  декодирование падало, JSON получался пустым — и рабочий конфиг объявлялся несовместимым уже
  на этапе замера скорости. Теперь добивка правильная, параметры `?…` отрезаются, мусорные
  символы удаляются, а `vmess` больше не проверяется по `id` вообще: если ссылка битая, скажет
  само ядро. Та же ошибка в добивке исправлена и в разборе конфигов.
- **Замер скорости — на настоящем списке конфигов с GitHub.** Если файл `speed_tested.txt`
  скачался через конфиг, значит через него реально достаётся зарубежный источник: скорость и
  доступность проверяются одним действием. Если GitHub не отдался — небольшие файлы Cloudflare
  и CacheFly, чтобы результат не зависел от одного сервиса.
- **Пустой пул на медленном канале больше не получается.** Параллельный замер делит скорость
  между дорожками, и при пороге 16 КБ/с ни один конфиг мог не пройти. Теперь, если параллельный
  заход не дал рабочих, приложение проверяет первые двадцать конфигов по одному — и пишет об
  этом в консоль. То же добавлено в импорт пула.
- **Поиск в браузере без POST.** Стартовая страница теперь своя: GET-форма поиска и ссылки на
  движки, у которых форма тоже GET (Mojeek, Bing, Brave). Формы с POST (включая поиск на самом
  `duckduckgo.com`) в браузере не работают — тело POST перехватить нельзя, а отправлять его
  напрямую нельзя тем более; вместо белого экрана показывается объяснение с подсказкой ввести
  запрос в адресной строке.

## Сборка

APK собирается автоматически из тега: `aapt2` → `javac` → `d8` → `zipalign` → `apksigner`,
подпись — `debug.keystore` из репозитория. В релизе: `WhitelistBypass-0.1.1.apk`,
`apk.sha256`, `build-report.txt` (badging, содержимое, сертификат, размер).

## Установка

1. Скачайте `WhitelistBypass-0.1.1.apk` из этого релиза.
2. Разрешите установку из неизвестных источников и установите — обновление ставится поверх
   предыдущей версии, данные и пул сохраняются.
3. Нажмите «Собрать пул»: vmess-конфиги, которые раньше отбрасывались, теперь будут измерены и
   попадут в пул, если проходят порог.
