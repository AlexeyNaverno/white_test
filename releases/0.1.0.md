# 0.1.0 — быстрее проверка, честнее конфиги, импорт пула

## Что нового

- **Ложная ошибка «vmess: id не UUID» убрана.** Xray принимает не только UUID: любую строку он
  сам переводит в UUID v5, поэтому конфиги с id вида «my-password» — рабочие. Раньше «Собрать
  пул» массово отбрасывал такие конфиги ещё до запуска ядра, хотя пинг у них проходил.
- **DPI-обход и автоподбор стратегий выключены по умолчанию.** Это надстройка на случай, когда
  прямое подключение не проходит, поэтому теперь она включается только галочкой в настройках.
  Включили — работает как раньше: подбор стратегии и её применение к линии до VPN-сервера.
- **Проверка сети по сервисам вне белых списков.** Цели пинга — `discord.com`,
  `www.instagram.com`, `x.com`, `www.facebook.com`, `www.youtube.com`. Разрешённые сайты
  отвечают всегда и ничего не говорят о том, работает ли обход.
- **Замер скорости стал короче.** Маленькие файлы (32 и 128 КБ) вместо мегабайтных, ожидание
  SOCKS 4 секунды вместо 6, таймаут замера 4 секунды, 4 параллельные дорожки по умолчанию,
  плюс меньше конфигов на один прогон (300 вместо 600) — при том же пороге.
- **Быстрый поиск больше не перепроверяет пул.** Он ищет новые конфиги и пропускает те, что уже
  в пуле: за них отвечает «Собрать пул», который заменяет пул целиком и выкидывает мёртвое.
- **Импорт и экспорт рабочих конфигов (.txt).** Настройки → «Пул: импорт и экспорт». Экспорт —
  по ссылке на строку. Импорт: дубликаты отбрасываются (внутри файла и относительно пула),
  остальные пингуются, у живых замеряется скорость, в пул попадают только прошедшие порог.
- **Абсолютно чёрный фон** в приложении и браузере — для OLED-экранов.
- **Консоль с прокруткой.** Лог больше не обрезается до последних строк: у окна фиксированная
  высота, ползунок и полная история, при новых сообщениях оно прокручивается вниз.

## Сборка

APK собирается автоматически из тега: `aapt2` → `javac` → `d8` → `zipalign` → `apksigner`,
подпись — `debug.keystore` из репозитория. В релизе: `WhitelistBypass-0.1.0.apk`,
`apk.sha256`, `build-report.txt` (badging, содержимое, сертификат, размер).

## Установка

1. Скачайте `WhitelistBypass-0.1.0.apk` из этого релиза.
2. Разрешите установку из неизвестных источников и установите — обновление ставится поверх
   предыдущей версии, данные и пул сохраняются.
3. После обновления стоит один раз нажать «Собрать пул»: у части конфигов, которые раньше
   ошибочно отбрасывались, скорость теперь будет измерена.
