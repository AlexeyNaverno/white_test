# 0.0.8 — отступы от системных панелей, Tor только с мостами

## Что нового

- **Интерфейс больше не залезает под камеру, статус-бар и кнопки навигации.** С Android 15
  приложение рисует под системными панелями, а отступы никто не добавлял: страница
  закрывала вырез камеры и мешала системным кнопкам. Теперь главный экран, настройки и
  браузер сами добавляют отступы по вставкам окна — включая вырез камеры и панель жестов.
- **Tor поднимается только с мостами.** Раньше при пустом списке мостов он стартовал
  открытым каналом — это и медленнее, и бессмысленно: для обычного интернета есть обычный
  браузер. Теперь `UseBridges 1` стоит всегда, а если мостов нет, приложение так и пишет:
  «нет мостов: добавьте их в настройках Tor» — вместо тихого падения в лог.
- **Понятная причина, когда Tor не поднялся.** Вместо общего «Tor не поднялся» теперь
  видно, что именно случилось: нет мостов, мост не ответил за отведённое время, истёк
  общий лимит ожидания.
- Порядок мостов по замерам скорости (кнопка «Проверить мосты и источники через Tor»)
  продолжает работать как раньше: первыми идут самые быстрые.

## Сборка

APK собирается автоматически из тега: `aapt2` → `javac` → `d8` → `zipalign` → `apksigner`,
подпись — `debug.keystore` из репозитория. В релизе: `WhitelistBypass-0.0.8.apk`,
`apk.sha256`, `build-report.txt` (badging, содержимое, сертификат, размер).

## Установка

1. Скачайте `WhitelistBypass-0.0.8.apk` из этого релиза.
2. Разрешите установку из неизвестных источников и установите — обновление ставится поверх
   предыдущей версии, данные и пул сохраняются.
3. Если нужен резервный канал Tor — Настройки → Tor: впишите мосты (или нажмите проверку,
   чтобы выбрать самые быстрые).
