# 0.1.7 — быстрее поиск, чёрный список нерабочих конфигов, настройки по разделам

## Что нового

- **Быстрый поиск больше не пингует всё впустую.** Пинг идёт порциями по 25 конфигов: как
  только порция дала живое — сразу проверяется скорость, и только если рабочего нет, пинг
  продолжается. Первый рабочий обычно находится за десятки секунд вместо нескольких минут:
  раньше приложение сначала пинговало все 150 конфигов партии, сортировало и только потом
  начинало проверку.
- **Чёрный список нерабочих конфигов.** Конфиг, который не дал данных (ядро не поднялось,
  SOCKS не открылся, таймаут), запоминается и **не пингуется** — ни в быстром поиске, ни в
  сборе пула. Запись живёт 7 дней (сервер может ожить), снимается сама, как только конфиг
  снова заработал, и чистится вручную: «Настройки → Данные → Очистить список нерабочих
  конфигураций».
- **Рабочие стратегии DPI сохраняются вместе с конфигами.** Если конфиг не дал данных
  напрямую, сбор пула пробует его через ciadpi (до 8 конфигов за сбор, по очереди — линия
  одна) и при удаче пишет в пул пару «конфиг + стратегия». При подключении берётся именно
  эта стратегия, а не «текущая из настроек». Отдельный список рабочих стратегий виден и
  забывается кнопкой на странице «Обход»; автоподбор пробует их первыми.
- **Настройки разбиты на разделы:** «Списки», «Обход», «Tor», «Данные», «Инфо» — вместо
  одной длинной прокрутки. «Сохранить» есть на каждой странице.
- **Новый раздел «Инфо»:** о проекте (открытый, без разработчика и владельца), донат
  (USDT jetton в сети TON) и идеи, которым нужна поддержка — свой медленный канал наружу,
  физические каналы под чебурнет, Meshtastic + LLM как шлюз наружу. Подробнее — `IDEAS.md`.
- **Проект больше не «чей-то»: разработчика нет.** README, описание в F-Droid и экран «Инфо»
  говорят это прямо: код под GPL-3.0, форкайте и переписывайте, серверов и аккаунтов у
  проекта нет.

## Сборка

APK собирается автоматически из тега: Gradle → ndk-build (нативные из исходников) →
zipalign/apksigner, подпись — `debug.keystore` из репозитория. В релизе:
`WhitelistBypass-0.1.7.apk`, `apk.sha256`, `build-report.txt` (badging, содержимое,
сертификат, размер).

## Установка

1. Скачайте `WhitelistBypass-0.1.7.apk` из этого релиза.
2. Разрешите установку из неизвестных источников и установите — обновление ставится поверх
   предыдущей версии, данные, настройки и пул сохраняются.
3. Проверьте быстрый поиск: он должен находить рабочий конфиг заметно раньше. Если в логе
   появилось «Чёрный список: N» — это нормально: приложение помнит, что уже не работало.
