# 0.1.4 — наборы настроек: «Стандарт» с DPI, «Wi-Fi», «Белые списки» и свои из .json

## Что нового

- **Новый набор по умолчанию «Стандарт»: DPI-обход включён.** Без него на живых блокировках
  подключение проходило «через раз» — теперь по умолчанию включены и DPI-обход линии, и
  автоподбор стратегий, а основной стратегией стоит комплексная фрагментация
  `-o1 -s1+s -s3+s -s6+s -s9+s -s12+s -s15+s -s20+s -s30+s -a1 -An` (одиночный disorder
  переживает не всяк DPI). Порог «рабочего» конфига снижен до **32 кбит/с (4 КБ/с)**, окно
  замера — **3000 мс**, таймаут пинга — **2000 мс**, смена конфига монитором — через **15 с**.
- **Скорость меряется на `generate_204`.** В проверке канала и в замере появились лёгкие
  адреса Cloudflare/Google/gstatic: ответ в десятки байт, поэтому «канал вообще живой?»
  выясняется мгновенно. Тела в таком ответе нет, поэтому скорость по нему не считается —
  он только подтверждает связность, и в плане замера такие адреса идут последними, а КБ/с
  считаются по настоящим файлам со списками конфигов с GitHub. Для HTTP-проверок в манифесте
  разрешён cleartext.
- **Три готовых набора настроек и свои — в списке рядом с импортом .json.** Набор — это
  целая пачка значений (пороги, таймауты, источники, DPI), а не одна галочка:
  - **Стандарт** — DPI-обход и автоподбор включены, порог 32 кбит/с, замер 3 с, пинг 2 с;
  - **Wi-Fi** — поведение 0.1.3: DPI и автоподбор выключены, порог 128 кбит/с, замер 1,5 с,
    пинг 1 с (самый быстрый сбор пула, но у оператора с DPI часто ничего не поднимается);
  - **Белые списки** — источники только «белые» (в адресе есть `white`), порог 16 кбит/с,
    две дорожки замера, окно 4 с, монитор 20 с, DPI-обход выключен (при белых списках он
    обычно мешает);
  - **Мой из .json** — всё, что вы импортируете, остаётся в этом же списке отдельным набором:
    вернуться к нему можно кнопкой, а не повторным поиском файла. Свои наборы удаляются,
    готовые — нет. В экспорт настроек свои наборы тоже попадают.
- **Миграция без сюрпризов.** Если настройки ни разу не меняли (старые значения по умолчанию
  целиком), приложение один раз переводит их на набор «Стандарт» — иначе новый DPI-режим
  просто не включился бы. Если что-то настраивали под себя, значения не трогаем: нужный
  набор можно применить вручную из списка.

## Сборка

APK собирается автоматически из тега: `aapt2` → `javac` → `d8` → `zipalign` → `apksigner`,
подпись — `debug.keystore` из репозитория. В релизе: `WhitelistBypass-0.1.4.apk`,
`apk.sha256`, `build-report.txt` (badging, содержимое, сертификат, размер).

## Установка

1. Скачайте `WhitelistBypass-0.1.4.apk` из этого релиза.
2. Разрешите установку из неизвестных источников и установите — обновление ставится поверх
   предыдущей версии, данные и пул сохраняются.
3. Откройте настройки → «Наборы настроек» и выберите подходящий: «Стандарт» (по умолчанию,
   с DPI-обходом), «Wi-Fi» (быстрый замер, без DPI) или «Белые списки» (низкий порог, только
   white-источники). После смены набора нажмите «Собрать пул»: у нового набора другие
   источники и пороги, и старый пул лучше перемерить.
