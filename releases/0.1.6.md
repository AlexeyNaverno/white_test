# 0.1.6 — быстрый сбор пула и понятные отказы ядра

## Что нового

- **Замеры больше не уходят в пустоту.** Ядро Xray 26 отказывается поднимать VLESS/Trojan
  без TLS к публичному адресу (правило `requiresTransportSecurity`: разрешены только
  приватные IP и локальные домены). Под него попадает больше половины публичных списков —
  в присланной консоли это 61 отказ из 90 замеров: TCP-пинг у таких конфигов проходит,
  они считаются живыми, занимают дорожку и падают одной и той же ошибкой.
  Теперь такие конфиги отсекаются сразу после загрузки списков, а в логе одна строка
  вида «Несовместимы с ядром: 63 (ядро Xray 26 не пускает без TLS — нужен security=tls
  или reality — 61; …)».
- **Появилась настройка «Ядро Xray» → «Разрешать конфиги без TLS».** С ней эти конфиги
  тоже работают: ядро подключается к локальному ретранслятору на 127.0.0.1 (для проверки
  ядра это «свой» адрес), а ретранслятор отдаёт соединение настоящему серверу — при
  включённом DPI-обходе через ciadpi, то есть фрагментация применяется к настоящему
  соединению, а не к локальному хопу. По умолчанию **выключено**: отключать проверку
  безопасности ядра без ведома пользователя неправильно.
- **Ошибки ядра в логе стали короткими.** Вместо «ядро не запустилось: ядро не
  запустилось: config error: infra/conf/serial: failed to parse json config > …» — суть:
  «ядро не запустилось: ядро Xray 26 не пускает без TLS — нужен security=tls или reality».
- **Разбор ссылок стал терпимее.** `security=true/false/1/0` в ссылке больше не считается
  «неизвестным шифрованием» (раньше давало «шифрование «false» ядро не умеет»), а
  собственное шифрование VLESS (`encryption=mlkem…`) передаётся в ядро как есть и
  разрешает работу без TLS.
- **Пул и быстрый поиск** используют ту же проверку: в пул из прошлых версий больше не
  попадают конфиги, которые текущее ядро принять не может.

## Сборка

APK собирается автоматически из тега: Gradle → ndk-build (нативные из исходников) →
zipalign/apksigner, подпись — `debug.keystore` из репозитория. В релизе:
`WhitelistBypass-0.1.6.apk`, `apk.sha256`, `build-report.txt` (badging, содержимое,
сертификат, размер).

## Установка

1. Скачайте `WhitelistBypass-0.1.6.apk` из этого релиза.
2. Разрешите установку из неизвестных источников и установите — обновление ставится поверх
   предыдущей версии, данные, настройки и пул сохраняются.
3. Если в логе много «Несовместимы с ядром» — откройте настройки, раздел «Ядро Xray»,
   и включите «Разрешать конфиги без TLS (через локальный ретранслятор)», затем соберите
   пул заново.
