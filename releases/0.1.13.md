# 0.1.13 — рабочие конфиги в настройках, два пула и «только DPI»

Пять изменений, которые просили: выбор конкретного VPN, отдельная вкладка рабочих конфигов,
вставка из буфера, режим без VPN для YouTube/Discord и разделение пулов по типу сети.
Плюс главный экран переделан под OLED.

## Рабочие конфиги — первая вкладка настроек

- «Рабочие» теперь **первая вкладка** настроек: до пула больше не надо добираться через
  «Данные → Открыть рабочие конфиги».
- Отдельный экран остался (кнопка «Рабочие» на главном), но это тот же блок `PoolPanel`, а не
  вторая копия разметки. Функциональность прежняя: пинг, перемер, удаление, чёрный список и
  «в чёрный список все нерабочие».

## Подключение к конкретному серверу

- У каждой строки пула — кнопка **«Подключить этот конфиг»**: поднимается ровно этот сервер,
  без перебора остальных и без резерва Tor. Порядок попыток прежний: если конфиг замерен через
  обход — сначала с той же стратегией, иначе сначала напрямую, вторая попытка одна.
- Строка сразу показывает, чем конфиг замерен: «обход: <стратегия>» или «напрямую».

## Конфиги из буфера обмена

- Сверху вкладки — **«Вставить из буфера»**: текст из буфера проходит тот же путь, что импорт
  файла — дедупликация, пинг, замер скорости, в пул только прошедшее порог. Рядом остался
  «Из файла» и прежний экспорт `.txt`.

## Два пула: Wi-Fi и LTE

- Замеры хранятся раздельно: `files/pool_wifi.txt` и `files/pool_lte.txt`. У домашнего Wi-Fi и
  у оператора разные блокировки; «собранный в метро» список дома только мешал, вытесняя хорошие
  домашние конфиги по скорости.
- Тип сети определяется автоматически (`Net`): Wi-Fi или мобильный; неизвестное считается
  мобильным. Подключение и поиск всегда берут пул **текущей** сети, переключатель на вкладке
  позволяет смотреть и чистить любой.
- Стратегии DPI теперь тоже по сетям: `dpi_strategy_wifi` для Wi-Fi и `dpi_strategy` для
  мобильного. Пустое поле = встроенная для этой сети («для Wi-Fi» или «для белых списков»).
- Старый `pool.txt` при первом запуске переносится в мобильный пул, Wi-Fi-пул создаётся пустым:
  старые замеры делались в мобильной сети, приписывать их Wi-Fi было бы враньём.

## Вкладка «Только DPI»

- Режим без VPN-сервера, для YouTube, Discord и Instagram: локальный `ciadpi` фрагментирует TLS
  на самом телефоне, трафик уходит напрямую, чужого сервера в цепочке нет.
- Своя стратегия и свой список адресов для проверки. Если ни один адрес не открылся, режим не
  включается: иначе телефон показывал бы «подключено», а YouTube оставался закрытым.
- В этом режиме монитор и «Переключить» не работают — переключать нечего; кнопка убрана и из
  уведомления.
- Быстрый вход с главного: кнопка **«DPI»** в линейке действий.

## Главный экран под OLED

- Фон чистый чёрный, карточек нет: состояние, большая круглая кнопка, строка пула — и всё.
- Все вспомогательные действия собраны в **одну линейку** высотой в одну кнопку:
  «Поиск», «Пул», «Рабочие», «DPI», «Журнал».
- Консоль скрыта; открывается кнопкой «Журнал» и раскрывается сама при ошибке.
- Функциональность не урезана: те же действия, те же настройки, отдельный экран рабочих
  конфигов тоже на месте.

- новые классы: `Net` (тип сети), `PoolPanel` (рабочие конфиги как блок), `VpnStart` (единая

  (главный экран 0.1.13);

- проверка компиляции (aapt2 + ecj): 0 ошибок, 225 классов.

## Установка

APK подписан тем же `debug.keystore`: обновление ставится поверх 0.1.12 без удаления данных
(пул и отметки сборки переживут обновление; старый `pool.txt` будет перенесён автоматически).
