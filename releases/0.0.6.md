# 0.0.6 — новые источники и автообновление стратегий DPI

## Что нового

- **Пять новых репозиториев в списке по умолчанию.** `luxxuria/harvester` (списки, уже
  отсортированные по скорости и пингу), `kort0881/vpn-vless-configs-russia` (RU-SNI и
  общий сборник), `tiagorrg/vless-checker` (JSON с результатами автопроверки ключей),
  `26info/vless-proxy-list` (рабочие прокси). `igareck/vpn-configs-for-russia` был и
  раньше — теперь его файлы идут в осмысленном порядке.
- **Порядок источников по ценности.** Сначала небольшие списки, которые их авторы уже
  проверили на пинг и скорость, потом массовые сборники, самый большой файл — последним:
  он больше не съедает лимит времени раньше полезных источников. Общий бюджет загрузки
  увеличен до 120 с.
- **Ссылки вытаскиваются из любого формата.** JSON, markdown, HTML — ссылки `vless://`,
  `vmess://`, `trojan://`, `ss://` находятся в строке, поэтому `keys.json` от
  vless-checker используется без отдельного парсера.
- **Автообновление стратегий DPI-обхода.** Стратегии ciadpi (ByeDPI) скачиваются из
  `romanvht/ByeByeDPI` и `alimali54/DPIscord`: кнопка «Обновить стратегии с GitHub» в
  настройках или обычный «Собрать пул». Встроенный минимум остаётся, даже если сеть
  недоступна.
- **Проверка стратегий вживую.** Кнопка «Проверить стратегии сейчас» и автоподбор при
  подключении по очереди поднимают ciadpi и идут через него на заблокированные адреса.
  Первая сработавшая стратегия сохраняется и применяется к линии до VPN-сервера —
  ручной перебор аргументов больше не нужен (автоподбор отключается в настройках).
- URL списков стратегий и адреса для проверки редактируются в настройках.

## Сборка

APK собирается автоматически из тега: `aapt2` → `javac` → `d8` → `zipalign` → `apksigner`,
подпись — `debug.keystore` из репозитория. В релизе: `WhitelistBypass-0.0.6.apk`,
`apk.sha256`, `build-report.txt` (badging, содержимое, сертификат, размер).

## Установка

1. Скачайте `WhitelistBypass-0.0.6.apk` из этого релиза.
2. Разрешите установку из неизвестных источников и установите — обновление ставится поверх
   предыдущей версии, данные и пул сохраняются.
3. Настройки → «DPI-обход» → «Обновить стратегии с GitHub», затем при необходимости
   «Проверить стратегии сейчас».
